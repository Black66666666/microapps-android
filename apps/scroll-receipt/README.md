# Scroll Receipt

Gate 0A Android experiment for the Scroll Receipt product.

Normal counting has no Start button. Once the user enables the Accessibility service, Android can deliver supported events while the Scroll Receipt activity is closed. The buttons inside Accuracy diagnostics only establish a controlled manual test baseline.

Gate 0A has no `INTERNET` permission and does not capture screenshots, audio, video, messages, captions, comments or typed text.

The current release criterion is physical-device validation of TikTok, Instagram Reels and YouTube Shorts with <=5% counter error and correct timing/exit behavior. Product and test decisions are in `docs/scroll-receipt/`.
